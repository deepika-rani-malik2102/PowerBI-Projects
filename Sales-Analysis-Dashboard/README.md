# 📊 Sales Analysis Dashboard – Power BI

## 📌 Project Overview
This project is an interactive Sales Analysis Dashboard built using Power BI to analyze business performance across regions, products, and time periods.
The dashboard helps stakeholders monitor revenue, profit, and order trends to make data-driven decisions.

## 🎯 Business Objectives

Monitor overall sales performance

Analyze profit and profit margins

Identify top-performing products

Compare regional sales performance

Track monthly sales trends

## 📊 Key Performance Indicators (KPIs)
1. Total Sales
2. Total Profit
3. Total Orders
4. Profit Margin (%)

## 🛠 Tools & Technologies Used
Power BI Desktop
DAX (Data Analysis Expressions)
Data Modeling
Power Query (Data Cleaning & Transformation)


## 🖼 Dashboard Preview & Features
Interactive slicers (Region, Date, Product)
KPI cards for quick performance view
Bar charts for regional comparison
Line chart for monthly trend analysis
Product-level sales insights
